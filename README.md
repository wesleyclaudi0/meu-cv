# Gerador de Currículo

Gerador de currículo em **uma coluna**, otimizado para ATS (Gupy, Kenoby etc.).
Preencha o formulário, veja o currículo ao vivo e baixe em PDF.

- Currículo de uma coluna, sem tabelas nem imagens, com texto selecionável no PDF
- Importar e salvar JSON (aceita também o JSON do gerador original)
- Idiomas com nível
- Nota ATS (estimativa por regras) e compatibilidade com a descrição de uma vaga

Tudo roda no navegador: seus dados ficam só no seu computador (localStorage).

Para usar localmente, abra o `index.html`.
